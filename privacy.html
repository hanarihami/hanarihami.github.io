Healing Sounds Agent

プライバシーポリシー

最終更新日：2026年10月26日

1. 取得する情報

Healing Sounds Agent（以下「本ツール」）は、運営者本人のGoogleアカウントで許可を受けた範囲で、次の情報にアクセスします。

  • Googleドライブ：運営者が指定したフォルダ内の音楽ファイル・画像・設定ファイルの読み取り、および本ツールが作成したファイルの保存
  • YouTube：運営者のチャンネルへの動画のアップロードと公開予約、動画情報の設定

2. 利用目的

取得した情報は、運営者のYouTubeチャンネルに動画を作成・投稿する目的にのみ使用します。

3. 第三者への提供

取得した情報を販売したり、第三者に提供したりすることはありません。動画の説明文の作成に、AIサービス（Anthropic社のAPI）へ曲名やテーマなどの文字情報を送ることがありますが、個人情報は含みません。

4. 保存と削除

処理のためにダウンロードしたファイルは、処理が終わると削除します。許可は、Googleアカウントの「セキュリティ」→「サードパーティのアクセス」からいつでも取り消せます。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによるGoogle APIから受け取った情報の使用は、限定的使用の要件を含む「Google API サービスのユーザーデータに関するポリシー」に従います。

Privacy Policy (English)

Healing Sounds Agent is used only by the channel owner. It accesses the owner's Google Drive (reading the owner's own music files and saving files it creates) and the owner's YouTube channel (uploading and scheduling videos), solely to publish videos to that channel. Data is never sold or shared with third parties. Downloaded files are deleted after processing. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account security settings.
